# AirCade ✈️🕹️

An 8-bit pixel-art plane crash survival game, playable offline during flights.

> **Survive. Craft. Escape.**
> You crash-land on a tropical island. Gather resources, build campfires to survive freezing nights, find 3 radio parts to call rescue and win.

## Quick Start

```bash
cd aircade
npm install
npm run dev      # → http://localhost:5173
```

See [`aircade/WORKFLOW.md`](aircade/WORKFLOW.md) for the full project guide.
