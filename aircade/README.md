# AirCade ✈️🕹️

8-bit pixel-art plane crash survival game. Built with React + Phaser 3, wrapped for Android via Capacitor.

## Setup

```bash
npm install
npm run dev         # Dev server → http://localhost:5173
```

## Android Build

```bash
npm run build       # Compile to dist/
npx cap sync        # Copy into Android project
npx cap open android # Open Android Studio → Run ▶️
```
